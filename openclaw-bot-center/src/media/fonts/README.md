# Media UI Fonts

These local WOFF2 assets are the project UI families declared by
`src/media/mediaFonts.css`: DM Sans v17 and Noto Sans SC v40. They were
copied from Fontsource 5.3.0 packages on 2026-08-31:

- `@fontsource-variable/dm-sans@5.3.0`
- `@fontsource-variable/noto-sans-sc@5.3.0`

Both fonts are licensed under SIL Open Font License 1.1. The license text is
included as `OFL-1.1.txt`; the upstream metadata identifies the Google Fonts
source and family attribution.
