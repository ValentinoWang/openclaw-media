# OpenClaw Media v1.0.0 Baseline

Release date: 2026-07-02

Status: released

This release publishes the converged local `selfmedia-tools` structure as the
OpenClaw Media v1.0.0 baseline.

## Included

- `selfmedia/`: reusable selfmedia business workflows.
- `media_model/`: field contracts, payload validation, write policy, and writer
  ports.
- `media_vault/`: artifact and evidence storage APIs.
- `integrations/`: Feishu and platform-auth integration implementations.
- `runtime/`: CLI, maintenance, deploy, backfill, and sync scripts.
- `openclaw-tag-router/`: OpenClaw router source of truth.
- `common/`, `config/`, `docs/`, and `tests/`.

## Excluded

- Tenant runtime data under `data/media_memory/tenants/<tenant_id>/` and
  `data/media_vault/tenants/<tenant_id>/`.
- Downloaded videos, images, audio, extracted frames, generated outputs, and
  local virtualenvs.
- Local secrets, cookies, tokens, private env files, Feishu readback evidence,
  and production workspace artifacts.

## Baseline Boundaries

`openclaw-tag-router/` is the source copy. The active OpenClaw plugin directory is
a deployment target, not the edit source.

`media_model/` owns contracts and writer ports. Concrete Feishu writing belongs
under `integrations/feishu/`.

`media_vault/` is code. `data/media_vault/` is runtime artifact storage and is
not committed.

The legacy numbered Part directories are retired from runtime source of truth.
