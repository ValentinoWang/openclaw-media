现状体检

问题不是「不好看」，是「没有系统」

对 src/media/** 共 19,460 行 CSS 的静态扫描结果。 这四个数字不需要审美判断——它们本身就是结论。

无过渡的悬停态
174 / 182

182 个 :hover，只有 8 条 transition。鼠标划过时颜色 0ms 跳变——「廉价感」最直接的来源。

最常用正文字号
10.9 px

出现 107 次。最小在用字号 8.5px。而 Hero 标题是 53px——比例失控到 5:1。

散装字号种类
89 种

从 .53rem 到 3.35rem，没有可辨认的字阶。同一层级的文字在不同页面是不同大小。

硬编码色值
132 种

分布在 200 处。4 个 Studio 页各自复制了一份 Hero CSS，只有色值不同。

核心论证

同一段 HTML，只换一组 CSS 变量

下面左右两侧是逐字符相同的 DOM。唯一差别是左侧套了一层 .legacy， 把字阶、圆角、阴影、动效四组 token 换回代码库现在的真实数值。 这证明了改造不需要重写组件——只需要补一层 token。

现状 正文 10.9px · 圆角 5px · 过渡 0ms

问题 标题和正文几乎同重，扫读时抓不到层级；卡片边缘锐利、无投影，与背景黏在一起；悬停无反馈。

改造后 正文 14px · 圆角 12px · 过渡 190ms

改动 标题升到 17px/700，副文案 12px 收窄；进度条换成五段流水线轨道，当前阶段高亮；加封面缩略图与平台标——内容本身成为视觉主体。
